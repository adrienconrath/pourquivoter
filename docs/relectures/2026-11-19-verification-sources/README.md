# Vérification des affirmations contre les sources — 19 novembre 2026

Passe ciblée sur les données inexactes ou non soutenues par leurs sources. Les 275 cases (11 candidatures × 25 thèmes) ont été relues : un premier relecteur a rouvert les sources citées et confronté chaque chiffre, date, attribution et mesure ; un second, indépendant, a tenté de réfuter chaque correction proposée en rouvrant lui-même la source.

## Résultat

- 426 corrections proposées, 398 confirmées par la contre-vérification ; 393 appliquées dans 196 cases (5 confirmées mais non appliquées automatiquement car le texte à remplacer n'était pas unique ou visait un titre de source).
- Par nature : 219 affirmations non soutenues par la source citée, 52 attributions (qui dit quoi), 25 chiffres (périmètre, année, unité), 22 erreurs factuelles, 75 tournures difficiles à lire.
- Les relevés détaillés (texte avant, texte après, preuve citée) sont dans [corrections.json](corrections.json). Les sources rouvertes et celles qui n'ont pas pu l'être (paywall, vidéo, blocage) sont dans [sources-relues.json](sources-relues.json) : 2792 lectures, 555 sources signalées illisibles.

## Limites

- Une source illisible n'a pas été tenue pour fausse : l'affirmation correspondante est conservée telle quelle.
- Les relecteurs sont des modèles d'IA ; la contre-vérification réduit le risque d'erreur sans l'annuler. Les corrections sont à relire en revue de PR.
- Cette passe ne renouvelle pas les recherches sur les programmes et ne change pas la date d'arrêt de l'édition.
